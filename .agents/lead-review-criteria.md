Lead review criteria for all sub-agents:

1. Evidence beats opinion.
2. Any "best" claim must be tied to measurable criteria.
3. Local project findings need file/line references.
4. Current-market claims need current sources.
5. No code edits. No speculative rewrites.
6. Separate:
   - product/market comparison
   - code/runtime risk
   - benchmark methodology
7. Flag missing data plainly.
8. A useful answer can be negative. Do not force a positive verdict.
